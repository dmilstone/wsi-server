Normal release

1. Development gate

cd /Users/dm026/Downloads/wsi-server_works
git status --short
./mvnw clean test
node --test src/test/js/*.test.js
git push origin feature/multichannel-viewer
Stop if Git is dirty or any test fails.

2. Stage

wsi-release stage --step
wsi-release verify staging
Browser 8082: staging banner; expected deidentified slides; open, pan, zoom, channels, annotations, exports; no CSRF/403 errors.

3. Rehearse production mode

wsi-release rehearse --step
wsi-release verify rehearsal
Browser 8083: no banner; production layout; exact staging behavior; rehearsal-only data. Production remains available.

4. Promote

wsi-release promote --step
wsi-release verify production
Type PROMOTE only after staging and rehearsal match and the rollback backup verifies.

5. Tag after browser validation

wsi-release tag production-YYYY-MM-DD-description
Browser 8080: normal layout; authorized slides; pan, zoom, channels, annotations, exports; no CSRF/403 errors; other environments remain isolated.

Troubleshooting and Recovery

Status

wsi production status
wsi staging status
wsi rehearsal status
wsi development status
wsi-release status
wsi-release verify staging
wsi-release verify rehearsal
wsi-release verify production

Logs

wsi production logs
wsi staging logs
wsi rehearsal logs
wsi development logs

Press Control-C to stop following a log.

Troubleshooting modes

wsi-release stage --dry-run
wsi-release stage --step --verbose
wsi-release rehearse --dry-run
wsi-release promote --dry-run
wsi-release history
  • --dry-run: no changes.
  • --step: Enter runs; p repeats; q exits safely.
  • Never bypass PROMOTE or ROLLBACK.

Rollback

wsi-release history
wsi-release rollback --step
wsi-release verify production
Rollback never restores, replaces, or overwrites annotations.

Stop conditions

  • Dirty Git worktree or failed tests
  • Git HEAD differs from staging commit
  • Recorded and calculated SHA-256 differ
  • Staging and rehearsal differ
  • Environment marker, identity, image root, or port mismatch
  • Expected port does not bind
  • Browser regression in security, layout, images, annotations, or exports
