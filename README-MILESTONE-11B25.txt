Milestone 11B.25 - Thumbnail terminology correction

Corrects the remaining user-visible terminology in the Slide Overview interface.

Changes:
- "Whole-slide macro overview" is now "Whole-slide thumbnail overview".
- Toolbar tooltip and accessibility labels now use "thumbnail overview".
- Enlarged-view title now uses "Whole-slide thumbnail overview".
- Thumbnail image alternative text and unavailable message now use thumbnail terminology.

This milestone changes user-visible text only. Existing backend endpoints and internal identifiers remain unchanged for compatibility.
