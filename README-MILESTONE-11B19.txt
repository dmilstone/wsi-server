Milestone 11B.19 - Independent enlarged label and macro views

Changes
- Adds a separate View larger action for the slide label.
- Adds a separate View larger action for the whole-slide macro overview.
- Clicking either preview image also opens its corresponding larger view.
- The larger image view is a closable modal overlay above the existing Slide overview popup.
- Close with the X button, Escape, or by clicking the dark backdrop.
- Keyboard focus returns to the control that opened the larger view.
- Missing label or macro images hide only their own enlarge controls.

Backend APIs are unchanged.
