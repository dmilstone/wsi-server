WSI Viewer Quick Guide

Initial viewing, channel display, annotations, and export

1. Open and navigate

  • Choose an image in Sample images.
  • Drag to pan; scroll or pinch to zoom.
  • Use viewer controls to reset or enter fullscreen.
  • Collapse side panels for more image space.

2. Adjust channels

  • Channel controls change presentation only, not source pixels.
  • Use checkboxes to show or hide channels.
  • Choose LUT color and adjust opacity.
  • Use Reset display or Recompute auto.

3. Work with annotations

  • Use Annotations and Names to show or hide overlays.
  • Select one annotation to view or edit its name.
  • Enter or leave the name field to commit; Escape cancels a draft.
  • Use drawing tools to create annotations and the available delete control to remove one.

4. Protect recent annotation work

  • Saving is asynchronous and currently has no visible Saved indicator.
  • After creating, moving, renaming, or deleting, pause several seconds before switching images, refreshing, or closing.
  • For important work, return to the image to confirm persistence.

5. Export

  • Selected annotation exports the selected region.
  • Entire View currently means the visible region, not necessarily the whole native slide.
  • Native exports are limited to 16,000,000 pixels. Zoom in and retry if no file appears.
  • A save-location prompt may appear. Confirm the PNG opens.

6. Environment and safety

  • Production normally has no warning banner.
  • DEVELOPMENT or STAGING means validation only and not clinical use.
  • Use only images appropriate for the assigned environment.
  • Never copy sensitive production material into development or staging.

Report: blank/distorted images, missing or changed annotations, failed exports, login errors, or unusual delays. Report the image name and approximate time; do not send sensitive image data outside the approved support process.

Before reporting a display problem, try one normal refresh - but never refresh while a recent annotation change may still be saving.
