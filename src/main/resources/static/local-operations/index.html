Local operations unavailable on this computer

Error: The Local WSI operations dashboard can only be opened from a browser that is running on the image-server host.

This viewer session is using host —, so this browser is not treating the request as loopback access to the dashboard on 127.0.0.1:8084.

Why: The dashboard listens only on loopback (127.0.0.1:8084) on the image server. Opening it from another computer would either hit that computer’s own localhost or be refused by the dashboard’s host-only boundary.

Recovery:

  1. Sit at (or remotely control) the image-server machine itself.
  2. On that machine, start the dashboard if it is not already running:
    set -a; source ops/wsi-ingest.conf; set +a
    export WSI_OPS_DASHBOARD_PASSWORD=your-password
    ./ops/start-wsi-ops-dashboard --daemon
  3. In a browser on that same machine, open the viewer via http://127.0.0.1:<viewer-port>/ or http://localhost:<viewer-port>/ (for example 8080 production or 8081 development).
  4. Use Dashboard / Local operations again, or open http://127.0.0.1:8084/ directly.

This browser appears to be on the image-server host. The ingestion dashboard is loopback-only and does not accept remote clients.

Dashboard is not listening on 127.0.0.1:8084. Start it with --daemon below, then use the open button (or refresh this page).

  1. cd to the WSI server repository root.
