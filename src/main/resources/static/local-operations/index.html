Local Operations

Image-server browser view for this workstation. The operations dashboard is on 127.0.0.1:8084 on this host, or on the image-server LAN address after remote bind is enabled.

Operations dashboard

Open the dashboard in a separate browser tab when the ops process is listening. This page does not proxy that service.

https://127.0.0.1:8084/ — daily dashboard (network drop, staging, image directory).

https://127.0.0.1:8084/services — launch, quit, or relaunch the image server and ingestion engine, individually or together.

https://127.0.0.1:8084/ingest-tools — in-depth ingest tools (seal/observe/promote, status). Useful for development, not the daily workflow.

Standalone WSI Control app

When the dashboard is down, or macOS blocks a background agent from starting Maven in Downloads, use the desktop app instead of a terminal.

  • macOS: double-click ops/macos/WSI Control.app, or run ops/macos/install-wsi-control-app.sh to put it in Applications and on the Desktop.
  • Windows 11: double-click ops/windows/WSI-Control.bat, or run ops/windows/install-desktop-shortcut.ps1.
