Milestone 11B.15 — Collapsible image information

Changes
- Moves Image information to the top of the image-browser column, directly below the sticky browser header.
- Converts the information block to an accessible collapsible details section.
- Persists the expanded/collapsed state in browser localStorage.
- Defaults to expanded until the user explicitly collapses it.
- Preserves the existing image metadata fields and all viewer/backend behavior.
